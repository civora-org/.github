# Civora

**Verejné zmluvy bez chaosu.**

Civora Zmluvy spája návrh, kontrolu a zverejnenie zmlúv obce či mesta v jednom nástroji, s verejným katalógom pre občanov. Postavené na open-source platforme [Decidim](https://decidim.org).
